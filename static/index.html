Finding links that work

On LinkedIn or Indeed, click Apply (not Easy Apply). If it opens a page on myworkdayjobs.com, greenhouse.io, lever.co or ashbyhq.com, paste that link here for a resume tailored to the full posting. For Greenhouse, Lever and Ashby, AutoApply also fills in the application. For any other site, paste the job description instead. You'll still get a tailored resume and can apply yourself.
